What Frost touches

1 permission storage, nothing else
0 connections every request is blocked
0 messages read blur is plain CSS
  • Only web.whatsapp.com, and only its look: blurring is plain CSS, switched on by attributes on the page’s root element and on the open chat panel.
  • Frost’s scripts never read your chats, names or photos, and never run inside WhatsApp’s own code. They only notice where you click or type (in the open chat, or on a chat in the list) and count the chat rows, so the popup can warn you if WhatsApp changes its layout.
  • No network access: the extension’s pages block every connection, and there is nothing to send to. Settings stay in this browser and are not synced.
  • Blur is visual. It stops people reading over your shoulder; it does not encrypt anything.
